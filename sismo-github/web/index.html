Comment lire le score ?

0 signifie des conditions très défavorables pour les placements risqués comme les actions, 50 une situation neutre, 100 des conditions très favorables. Chaque indicateur est comparé à ses dix dernières années, puis les indicateurs sont combinés selon leur poids. Les bandes de couleur du tracé montrent les seuils : sous 35, défavorable ; de 35 à 50, prudence ; au-dessus de 50, favorable.
